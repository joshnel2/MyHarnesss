# Founder Axioms

> These are my NON-NEGOTIABLE business principles.
> The Harness applies these to EVERY decision.
> When in doubt, check the axioms.

---

## Operational Axioms

### 1. Ship > Perfect
- If it takes more than 4 hours, cut the scope
- Launch with 80% and iterate
- "Good enough" today beats "perfect" next month
- Fix bugs in production (unless they're data-loss critical)

### 2. Simplicity is the Strategy
- Fewer features, done well
- If you can't explain it in one sentence, rethink it
- Complexity is a liability, not an asset
- Default to the boring technology

### 3. Speed is a Feature
- Fast responses to customers
- Fast deploys to production
- Fast decisions in meetings
- Fast "no" is better than slow "maybe"

### 4. Async First
- Default to written communication
- Meetings are for decisions, not updates
- No meetings on Tuesdays (Focus Day)
- Record everything for async consumption

### 5. Lean Operations
- Bootstrap mentality even with funding
- Every dollar should drive growth or product
- Automate before hiring
- Tools > headcount

---

## Product Axioms

### 6. Customer Pain > Feature Requests
- Solve the problem, not the requested solution
- Talk to users weekly
- Usage data > user opinions
- If no one's asking for it, don't build it

### 7. Human-in-the-Loop
- AI advises, humans decide
- Never automate accountability
- Shadow Mode is the default
- Trust is earned incrementally

### 8. Developer Experience Matters
- If it's hard to use, it won't be used
- Documentation is a feature
- APIs over UIs when possible
- Eat your own dogfood

---

## Team Axioms

### 9. Ownership > Permission
- Hire people who don't need to be managed
- Define the outcome, not the process
- Mistakes are data, not failures
- If you see a problem, you own it

### 10. Transparency by Default
- Share context, not just tasks
- Bad news travels fast (and that's good)
- Financials are visible to the team
- Roadmap is public internally

### 11. No Brilliant Jerks
- Culture fit is non-negotiable
- Disagree and commit
- We win as a team
- High performers who undermine others are net negative

---

## Communication Axioms

### 12. Be Direct
- Say what you mean
- Feedback is immediate
- No passive-aggressive bullshit
- If you're frustrated, say it (constructively)

### 13. Write It Down
- Decisions live in documents, not meetings
- One source of truth per topic
- Update docs or delete them
- If it's verbal, it's vapor

### 14. Metrics or It Didn't Happen
- Quantify everything measurable
- "It went well" is not a status update
- Weekly metrics review (async)
- Leading indicators > lagging indicators

---

## Strategic Axioms

### 15. Focus is a Superpower
- One bet at a time
- Finish before starting
- Kill projects that aren't working
- No to distractions is yes to priorities

### 16. Build for the Long Game
- Customer trust > short-term revenue
- Reputation is the moat
- Sustainable pace beats burnout
- We're building a marathon, not a sprint

---

## Decision Framework

When stuck, ask in this order:

1. **Does it serve the customer?** If no, stop.
2. **Is it simple?** If not, simplify.
3. **Can we ship it this week?** If not, cut scope.
4. **Does it align with our axioms?** If not, reconsider.
